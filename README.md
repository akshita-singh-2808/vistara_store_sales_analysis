# Retail Sales Analytics Dashboard
DASHBOARD PREVIEW
![Dashboard](images/dashboard.png)

**September 2025**

An interactive Excel dashboard developed to analyze retail sales performance and customer purchasing behavior. This project was built to strengthen data analysis and visualization skills using Microsoft Excel.

## Features

* Sales vs Orders trend analysis
* Channel-wise sales distribution
* Gender and age-group analysis
* Top-performing states identification
* Interactive filtering using slicers

## Skills Demonstrated

* Data Cleaning
* Pivot Tables
* Pivot Charts
* Dashboard Design
* Business Analytics
* Data Visualization

## Key Learnings

* Transforming raw business data into actionable insights
* Designing interactive dashboards for stakeholders
* Identifying trends and patterns across customer segments
* Presenting data through clear visualizations and KPIs

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting

## Project Outcome

Created a dynamic dashboard that enables users to explore sales performance across regions, customer demographics, and sales channels through interactive visualizations.
